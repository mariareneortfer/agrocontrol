# Backlog v0.1 — AgroControl

## Convención de prioridad

- P0: imprescindible para el flujo crítico del MVP.
- P1: importante para completar la operación.
- P2: complemento posterior.

### AC-001 — Registrar predios y parcelas
**Prioridad:** P0
Como administrador, quiero registrar predios y sus parcelas para representar la
estructura física sobre la que se planifica la producción.

### AC-002 — Gestionar cultivos
**Prioridad:** P0
Como administrador, quiero mantener el catálogo de cultivos para poder asociarlos a
las campañas.

### AC-003 — Crear una campaña sobre una parcela
**Prioridad:** P0
Como jefe de campo, quiero crear una campaña sobre una parcela para organizar el ciclo
productivo y todo lo que ocurra en él.

### AC-004 — Planificar labores de una campaña
**Prioridad:** P0
Como jefe de campo, quiero planificar las labores de una campaña para saber qué
trabajo debe ejecutarse y cuándo.

### AC-005 — Asignar un operario a una labor
**Prioridad:** P0
Como jefe de campo, quiero asignar un operario responsable a cada labor para que exista
un encargado identificable de su ejecución.

### AC-006 — Consultar mis labores asignadas
**Prioridad:** P0
Como operario, quiero consultar en el móvil las labores que tengo asignadas para saber
qué debo ejecutar en campo.

### AC-007 — Iniciar y completar una labor
**Prioridad:** P0
Como operario, quiero iniciar y completar una labor asignada para reflejar el avance
real del trabajo de campo.

### AC-008 — Registrar el consumo de insumos de una labor
**Prioridad:** P0
Como operario, quiero registrar los insumos consumidos en una labor para que el gasto
quede asociado al trabajo realizado y el stock refleje la realidad.

### AC-009 — Registrar entradas y salidas de insumos
**Prioridad:** P0
Como almacenero, quiero registrar los movimientos de insumos para mantener un stock
confiable antes de que se ejecuten las labores.

### AC-010 — Registrar la cosecha de una campaña
**Prioridad:** P0
Como jefe de campo, quiero registrar la cosecha obtenida en una campaña para cerrar el
ciclo productivo con información cuantificada.

### AC-011 — Registrar una observación o incidencia de campo
**Prioridad:** P1
Como operario, quiero registrar observaciones e incidencias durante la ejecución para
conservar trazabilidad de situaciones excepcionales.

### AC-012 — Consultar la bitácora de una parcela
**Prioridad:** P1
Como supervisor, quiero consultar la bitácora de una parcela para entender qué ocurrió
en ella a lo largo del tiempo.

### AC-013 — Consultar el avance de una campaña
**Prioridad:** P1
Como supervisor, quiero consultar el avance de una campaña para detectar retrasos y
labores pendientes.

### AC-014 — Consultar indicadores operativos
**Prioridad:** P1
Como supervisor, quiero un tablero de indicadores para entender el estado general de la
operación.

### AC-015 — Auditar cambios críticos
**Prioridad:** P2
Como administrador, quiero que las operaciones críticas queden auditadas para poder
explicar quién hizo qué y cuándo.
