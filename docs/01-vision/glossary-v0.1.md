# Glosario v0.1 — AgroControl

| Término | Significado inicial |
|---|---|
| Predio | Unidad productiva física administrada por el sistema. |
| Parcela | Porción de terreno identificable dentro de un predio sobre la que se ejecutan campañas y labores. |
| Cultivo | Especie o variedad que se siembra en una campaña. |
| Campaña | Ciclo productivo definido sobre una parcela, con un cultivo, un periodo y un estado. |
| Labor | Trabajo de campo planificado dentro de una campaña y una parcela. |
| Estado de labor | Situación de una labor: planificada, asignada, en ejecución, completada o cancelada. |
| Asignación de labor | Vínculo entre una labor y el operario responsable de ejecutarla. |
| Insumo | Bien consumible utilizado en las labores de campo. |
| Movimiento de insumo | Entrada o salida registrada que modifica el stock de un insumo. |
| Consumo de labor | Cantidad de un insumo efectivamente utilizada en una labor determinada. |
| Stock disponible | Cantidad de un insumo que puede consumirse en un momento dado. |
| Unidad de medida | Referencia explícita en que se expresa una cantidad de insumo o cosecha. |
| Bitácora de campo | Registro cronológico de lo ocurrido en una parcela: labores, consumos, observaciones e incidencias. |
| Incidencia | Hecho excepcional ocurrido en campo, vinculado a una parcela, campaña o labor. |
| Cosecha | Registro del producto obtenido al cierre o durante una campaña, con cantidad y unidad. |

> Este glosario es v0.1. Los significados pueden refinarse cuando aparezcan nuevas
> reglas, pero los cambios deberán quedar documentados.
